Git em 30 segundos

Git salva o histórico do seu código. Use git init para iniciar, git add . para salvar as alterações e git commit -m "mensagem" para criar um ponto na história.

O que é API?

Uma API é o garçom da web: ela leva o seu pedido ao servidor e traz a resposta de volta (como dados de clima, login ou pagamentos) para a sua aplicação.

SEO Básico

Para o Google achar seu site: use boas tags <h1>, escreva descrições nas imagens com alt e garanta que a página abra bem no celular.

Variáveis em JS

Use const para valores fixos que nunca mudam e let para valores que vão variar ao longo do código. Esqueça o antigo var.
